# 📊 Sales Data Analysis

A data analysis project that explores sales data using Python, Pandas, SQL, and data visualization techniques.

## ✨ Features

- Data cleaning and preprocessing
- Sales and revenue analysis
- Product-wise performance analysis
- Category-wise sales analysis
- Monthly sales trends
- SQL-based data analysis
- Data visualization

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- SQL
- Matplotlib
- Jupyter Notebook

## 🎯 Project Purpose

This project demonstrates how Python and SQL can be used to clean, analyze, and visualize sales data to identify useful business insights.
